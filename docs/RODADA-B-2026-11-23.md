# GetAll-Addon — expansão experimental do grupo B (2026-11-23)

## Critério e status

Foram reavaliados os 85 projetos de classe B a partir da auditoria existente. Doze receitas de instalação parcial foram geradas para releases Windows cujos ZIPs tiveram layout conferido. Cada receita usa schema_version=3, operations=[], inputs=[], manual_steps e required_files encontrados no pacote. Isto instala os arquivos públicos, mas não comprova jogabilidade com a mídia original. Status experimental. O host atual descobre apenas receitas validated.

Com o SDK v3, manual_steps mantém a instalação em PartiallyCompleted e não habilita Jogar agora. A receita não executa ferramentas externas e o usuário deve seguir o procedimento oficial do jogo. A extensão v4 em desenvolvimento pelo Codex não foi usada.

## Dependências genéricas do SDK

Phase Distorter 0.5: o schema v3 não aceita espaços nos nomes de arquivos necessários (Phase Distorter.exe); aguardar suporte seguro a nomes Windows comuns, sem renomear arquivos oficiais.

HarbourMasters e demais recompilados: precisam de comprovação do primeiro uso para promover a instalação de PartiallyCompleted a Completed, verificando os assets gerados. A operação first_run_files do SDK v4 ainda não estava publicada no SDK usado nesta rodada.

Cannonball, WipeOut, REDRIVER2 e outros projetos com conjuntos de dados originais requerem import_input_set ou operação equivalente segura, com cópia controlada e hashes. GGARecomp teve 404 no download do asset Windows consultado.

Recharged: foi usada a versão estável v1.1.7; não o prerelease de teste no topo da API.

## Testes executados

Os doze ZIPs foram baixados e inspecionados; cada executável e required_file foi encontrado no pacote. JSON, schema v3, IDs e tag conferidos. SHA-256 do JSON precisa ser calculado sobre os bytes do GitHub e confirmado após a publicação.

Nenhum teste fim a fim foi realizado com ROM/ISO legítima, nem houve validação de jogabilidade no Windows. Nenhum novo status validated foi atribuído. Conteúdo comercial não foi distribuído. O repositório do AllFix e seu catálogo, bem como o ZIP do addon universal v1.0.0, não foram alterados.

Os outros projetos conservam a classificação da auditoria integral e serão revisitados somente com evidências ou capacidades novas.
